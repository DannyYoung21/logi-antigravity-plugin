## 4. Privacy

The Plugin runs entirely on your Mac. It communicates only with the Antigravity language servers on your own
computer (127.0.0.1) and reads Antigravity's local session folders to show session status, token usage and limits.

The Developer does **not** collect, store, transmit, sell or share any personal data. The Plugin contains no
analytics, tracking or advertising and sends no data to the internet.

The "New Conversation" action asks macOS for the Accessibility permission for "Logi Plugin Service" so it can send
Antigravity's keyboard shortcut. You can revoke this permission at any time in System Settings.
